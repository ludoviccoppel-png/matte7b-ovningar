Differens

Skillnaden mellan två tal som följer på varandra. I 5, 8, 11, 14 är differensen +3.

Regel i ord

"Börja på 5 och öka med 3 varje gång." Regeln säger var följden börjar och hur den ändras.

Formel för figur n

Ökar mönstret med 3 per figur står 3 framför n: 3n + något. Kontrollera med figur 1: 3 · 1 + 2 = 5 ger 3n + 2.

Baklänges

Vilken figur har 38 stickor om formeln är 3n + 2? Lös 3n + 2 = 38 → 3n = 36 → n = 12.
