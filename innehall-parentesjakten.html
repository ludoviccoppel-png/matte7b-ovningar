Utveckla
Sikta med musen eller fingret och klicka eller tryck för att skjuta. Med tangentbordet: ← → siktar och mellanslag skjuter.
Kom ihåg: 3(x + 4) = 3 · x + 3 · 4 = 3x + 12. Talet framför multipliceras med alla termer. Minus framför en parentes byter tecken på alla termer: 3 − (x + 5) = 3 − x − 5 och 3 − (x − 5) = 3 − x + 5.
